# Inventory to register

One row per gap id from `docs/saxml-inventory.md`'s "Gap ids introduced" section (13 today). "Register entries and attributes" names `entry.id` / `attribute.name` pairs from `fm-adt-toolkit/gaps/register.json`, each an attribute with `reported: false` and no `wontfix` — a real gap by the register's own accounting. Most gap ids map to many register attributes; the list here is a representative sample, not the full set, except where the notes column says otherwise. Built by keyword search over a dump of every `reported: false, !wontfix` attribute in the register, then hand-matched to each gap id's description in the inventory.

Every gap id now resolves to a real register pair; there is no `OPEN ITEM` left. The last two were seeded on 2026-09-15 as register entries of their own, `calculation-tokens` and `plugin-call-sites` — both `op: none` entries whose probe is a `validate:calculation`, which is the op that comes closest to the question and answers none of it. `catalog-layout-options` was retired on 2026-09-14: fm's own layout flag table names both bits (confirmRecordSave, disableQuickFind), so the inventory rows became covered.

The calculation-text rows on script step kinds (for example `step:186`'s) are `reported: true` on purpose — they are the text fm does give you, not the missing tokens.
