# Plan 4: The Tabs

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port every catalog tab of the legacy inspector onto the Plan 3 model: a page shell with sidebar navigation and hash routing, then tabs for tables and fields, occurrences and relationships with the graph, scripts through the shared step renderer with a step index, layouts with the wireframe drawn from fm's parts and object bounds, security, themes (new in fm 0.7.0), and the remaining catalogs. Each tab renders from the solution model alone, works across files, and carries object-level re-read. The derived analyses (unreferenced, broken references, reference explorer, risk, call graph), exports, the Gaps tab, the count cross-check and the deletion of `legacy/` are Plan 5.

**Architecture:** Tabs are pure functions from the model to an HTML string in `ui/tabs/<name>.js`, one file per tab, tested in Node against the recorded ooe fixture with string assertions. `ui/shell.js` owns the sidebar, the `#tab/selection` hash route, the per-tab filter box and the delegated clicks (selection, re-read). `ui/dom.js` holds the few HTML helpers every tab uses (escape, dense table, key/value list, section, link). `ui/access.js` is the one accessor through which a tab reads an fm key, exact first and then case-and-separator folded, using the toolkit's `foldKey`. The toolkit's browser-safe `step-display` module is served by the server from `node_modules` and mapped through an import map so the same bare import works in the page and in Node.

**Tech Stack:** Node 22.19 (`node --test`), plain ESM in the browser and in Node, no bundler, no framework. `fm-adt-toolkit` v0.5.1 (`step-display` in the page; `runner`, `read-only` on the server). SVG for the wireframe and the relationship graph.

**Spec:** `docs/superpowers/specs/2026-09-14-fm-cli-rewrite-design.md` sections 2 and 3 (binding, as amended 2026-09-15 and 2026-09-16), section 5 porting step 3 and its testing paragraph. Parity checklist: `docs/saxml-inventory.md` `render` rows for `s.tables`, `s.graph`, `s.scripts`, `s.layouts`, `s.accounts`, `s.themes`, `s.valueLists`, `s.customs`, `s.menus`, `s.ext`, `s.baseDirs`, `s.persistent`, `s.fileMeta` (covered and derived rows only; gap rows are Plan 5 or the register).

## Global Constraints

- `ui/*.js` and `ui/tabs/*.js` import nothing from `node:` and nothing from `server/`. Their only external import is the bare specifier `fm-adt-toolkit/step-display`, resolved by the import map in the page and by `node_modules` in tests.
- Values from fm are read verbatim from the model. A tab reads a key through `get`/`path` in `ui/access.js` (exact, then folded). Never a hand-written alternative spelling.
- A tab's `render(solution, view)` is a pure function returning an HTML string. It never touches `document`, never fetches, never mutates the model. Every string from the model passes through `esc`.
- Every list is filterable by the shell's one filter box (case-insensitive substring over the row's text); every detail pane carries a re-read control for its object (`data-reread-object`), and every tab header a re-read control for its catalog (`data-reread-catalog`).
- Multi-file: every row names its file when the solution has more than one, and a selection key is `<file target>|<object id>`.
- `npm test` passes without fm and without network; the live smoke test stays gated on `INSPECTOR_LIVE=1`. Tab tests render from `tests/fixtures/ooe` (re-recorded in Task 2 with the theme catalog; fm 0.7.0 build 29823677).
- The legacy inspector is not modified and not read by the new code; the inventory is the parity checklist.

- `ui/shell.js`: `createShell({ tabs, mount, onReread })` where `tabs` is an ordered array of tab modules `{ id, label, render(solution, view) }`, `mount = { nav, main, filter, context }` DOM elements, `onReread(slot)` returns a promise. - `view = { selection: string|null, filter: string, multiFile: boolean }`.
- Tab module contract: `render(solution, view)` returns HTML; a list row has `data-select="<selection>"` and the shell rewrites the hash to `#<tab>/<selection>` on click; a re-read button has `data-reread-object='<json slot>'` or `data-reread-catalog` + `data-target` as in Plan 3.

// ui/dom.js
// The few HTML helpers every tab uses. Pure functions to strings; browser safe.
export function esc(s) {
  return String(s ?? '').replace(/[&<>"]/g, (c) => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c]));
}

export function matches(text, filter) {
  return !filter || String(text).toLowerCase().includes(filter);
}

export function count(n) {
  return `<span class="num">${Number(n) || 0}</span>`;
}

export function badge(text, tone = 'muted') {
  return `<span class="badge ${tone}">${esc(text)}</span>`;
}

export function link(hash, label) {
  return `<a href="#${hash.split('/').map(encodeURIComponent).join('/')}">${esc(label)}</a>`;
}

export function kv(pairs) {
  return `<dl class="kv">${pairs.map(([k, v]) => `<dt>${esc(k)}</dt><dd>${v ?? ''}</dd>`).join('')}</dl>`;
}

export function section(title, body, opts = {}) {
  return `<section class="panel"><header><h2>${esc(title)}</h2>${opts.actions ?? ''}</header>${body}</section>`;
}

export function table(columns, rows, opts = {}) {
  if (!rows.length) return `<p class="empty">${esc(opts.empty ?? 'None')}</p>`;
  const head = columns.map((c) => `<th${c.num ? ' class="num"' : ''}>${esc(c.label)}</th>`).join('');
  const body = rows.map((r) => {
    const cells = columns.map((c) => {
      const html = c.render ? c.render(r) : esc(r[c.key] ?? '');
      return `<td${c.num ? ' class="num"' : ''}>${html}</td>`;
    }).join('');
    const attrs = opts.rowAttrs ? ' ' + opts.rowAttrs(r) : '';
    return `<tr${attrs}>${cells}</tr>`;
  }).join('');
  return `<div class="table-wrap"><table><thead><tr>${head}</tr></thead><tbody>${body}</tbody></table></div>`;
}
```

// ui/access.js
// The one way a tab reads an fm key: exact spelling first, then the case-and-separator
// fold, because fm respells keys between builds (0.7.0 moved every multi-word key to
// camelCase). Word-level renames are the intake's job, not this file's.
import { foldKey } from 'fm-adt-toolkit/step-display';

export function get(obj, key) {
  if (obj === null || typeof obj !== 'object') return undefined;
  if (Object.hasOwn(obj, key)) return obj[key];
  const want = foldKey(key);
  for (const k of Object.keys(obj)) if (foldKey(k) === want) return obj[k];
  return undefined;
}

export function has(obj, key) {
  return get(obj, key) !== undefined;
}

export function path(obj, dotted) {
  let cur = obj;
  for (const seg of dotted.split('.')) {
    if (cur === null || typeof cur !== 'object') return undefined;
    cur = Array.isArray(cur) ? cur[Number(seg)] : get(cur, seg);
  }
  return cur;
}
```

```js
// ui/shell.js
// Sidebar, hash route, filter box, delegated clicks. Tabs are pure renderers; this is the
// only file in ui/ that touches the document besides app.js.
import { esc } from './dom.js';

export function parseHash(hash) {
  const h = (hash || '').replace(/^#/, '');
  if (!h) return { tab: null, selection: null };
  const [tab, ...rest] = h.split('/');
  return { tab, selection: rest.length ? decodeURIComponent(rest.join('/')) : null };
}

export function buildHash(tab, selection) {
  return selection ? `#${tab}/${encodeURIComponent(selection)}` : `#${tab}`;
}

export function createShell({ tabs, mount, onReread }) {
  let solution = null;
  let filter = '';
  const byId = new Map(tabs.map((t) => [t.id, t]));

  function current() {
    const { tab, selection } = parseHash(location.hash);
    return { tab: byId.has(tab) ? tab : tabs[0].id, selection };
  }

  function renderNav(active) {
    mount.nav.innerHTML = tabs.map((t) =>
      `<a class="nav-item${t.id === active ? ' active' : ''}" href="${buildHash(t.id, null)}">${esc(t.label)}</a>`).join('');
  }

  function route() {
    if (!solution) return;
    const { tab, selection } = current();
    renderNav(tab);
    const view = { selection, filter, multiFile: Object.keys(solution.files).length > 1 };
    mount.main.innerHTML = byId.get(tab).render(solution, view);
  }

  mount.filter.addEventListener('input', () => { filter = mount.filter.value.trim().toLowerCase(); route(); });
  window.addEventListener('hashchange', route);
  mount.main.addEventListener('click', async (ev) => {
    const reread = ev.target.closest('button[data-reread-object], button[data-reread-catalog]');
    if (reread) {
      const slot = reread.dataset.rereadObject
        ? JSON.parse(reread.dataset.rereadObject)
        : { kind: 'catalog', target: reread.dataset.target, catalog: reread.dataset.rereadCatalog };
      await onReread(slot);
      return;
    }
    const row = ev.target.closest('[data-select]');
    if (row && !ev.target.closest('a')) {
      const { tab } = current();
      location.hash = buildHash(tab, row.dataset.select);
    }
  });

  return {
    setSolution(s) { solution = s; route(); },
    route,
    get view() { return { ...current(), filter }; },
  };
}
```
